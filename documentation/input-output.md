# DELT-Hit CLI input/output reference

Compiled from `documentation/cli.md`, `pixi run delt-hit --help`, and the current implementations under `src/delt_hit/cli/`.

| CLI module | Command | Primary inputs | Optional / mode-changing inputs | Outputs | Notes |
|---|---|---|---|---|---|
| `init` | `delt-hit init` | `--excel_path <library.xlsx>` | None documented | `<save_dir>/<experiment_name>/config.yaml` | Reads the Excel template and writes the project YAML config. |
| `demultiplex` | `delt-hit demultiplex prepare` | `--config_path <config.yaml>` | `--fast_dev_run` | `<save_dir>/<experiment_name>/demultiplex/cutadapt_input_files/` including barcode FASTQ files and `demultiplex.sh` | Generates Cutadapt inputs and an executable shell script, but does not execute it. |
| `demultiplex` | `delt-hit demultiplex process` | `--config_path <config.yaml>` | `--as_files`, `--sort_by_counts` | `<save_dir>/<experiment_name>/selections/<SELECTION_NAME>/counts.txt` or flat count files, depending on `--as_files` | Consumes `cutadapt_output_files/reads_with_adapters.gz` plus the latest `*.cutadapt.json` to compute per-selection counts. |
| `demultiplex` | `delt-hit demultiplex report` | `--config_path <config.yaml>` | None | `<save_dir>/<experiment_name>/qc/report.txt` | Reads Cutadapt output stats and writes a text QC summary. |
| `demultiplex` | `delt-hit demultiplex qc` | `--config_path <config.yaml>` | None | `<save_dir>/<experiment_name>/qc/` plot files | Generates QC plots from demultiplexed output. |
| `library` | `delt-hit library enumerate` | `--config_path <config.yaml>` | `--debug {all,valid,invalid}`, `--overwrite`, `--errors {raise,ignore}`, `--counts_path`, `--top_n`, `--library_name` | Default: `<save_dir>/<experiment_name>/library/library.parquet` | If `--counts_path` is provided, filtered enumeration is used and `--library_name` is required. |
| `library` | `delt-hit library enumerate` | `--config_path <config.yaml>` with filtered mode inputs | `--counts_path <.../counts.txt>`, `--top_n`, `--library_name`, plus debug/error flags above | Filtered mode: `<save_dir>/<experiment_name>/library/<library_name>.parquet` | `--counts_path` must contain matching `code_*` columns from demultiplex counts output. |
| `library` | `delt-hit library enumerate` | same as above | `--debug all|valid|invalid` | Debug PNGs in `<save_dir>/<experiment_name>/library/reaction_graph_combination=<index>_<codes>.png` | Debug images are produced alongside the parquet output. |
| `library` | `delt-hit library properties` | `--config_path <config.yaml>` | `--library_name`, `--library_path` | `<save_dir>/<experiment_name>/library/properties/<library_name>/properties.parquet` and per-property histogram PNGs in the same directory | Uses the default `library.parquet` unless overridden by `--library_name` or `--library_path`. Not supported for dual-display outputs with `smiles_a`/`smiles_b`. |
| `library` | `delt-hit library represent` | `--config_path <config.yaml>` | `--method morgan|bert`, `--library_path` | `<save_dir>/<experiment_name>/representations/morgan.npz` or `bert.npz` | Current CLI routes both `morgan` and `bert` through Morgan fingerprint generation in the wrapper. |
| `visualize` | `delt-hit visualize enumerate` | `--config_path <config.yaml>` | `--building_block_ids`, `--dpi`, `--tile_size`, `--graph`, `--reactions`, `--building_blocks`, `--compounds` | `<save_dir>/<experiment_name>/library/visualization/` | If no selector flags are passed, it generates all visualization types below. |
| `visualize` | `delt-hit visualize enumerate` | same as above | `--graph` | `library/visualization/reaction_graph.png`, `reaction_graph_additional.png`, `reaction_graph_building_blocks.png` | Writes reaction graph panels. |
| `visualize` | `delt-hit visualize enumerate` | same as above | `--reactions` | `library/visualization/reactions/*.png` | Writes reaction scheme panels from configured SMIRKS. |
| `visualize` | `delt-hit visualize enumerate` | same as above | `--building_blocks`, optional `--building_block_ids` | `library/visualization/building_blocks/<BUILDING_BLOCK_ID>/*.png` | Writes one panel per building block entry with a non-null SMILES. |
| `visualize` | `delt-hit visualize enumerate` | same as above | `--compounds` | `library/visualization/compounds/*.png` | Writes one panel per configured compound with a non-null SMILES. |
| `visualize` | `delt-hit visualize library` | `--config_path <config.yaml>`, `--library_name <name>` | `--dpi`, `--tile_size` | `<save_dir>/<experiment_name>/library/visualization/libraries/<library_name>/*.png` | Reads `<save_dir>/<experiment_name>/library/<library_name>.parquet` and writes one PNG per entry, named from `code_*` columns when present. |
| `analyse` | `delt-hit analyse enrichment` | Always: `--method`, `--save_dir`, `--name` | For `counts`, `edgeR`, `DESeq2`: `--analysis_config`; for `z_score`: `--config_path`, `--counts` | Method-specific outputs under `<save_dir>/<method>/<name>/` for `counts` and `edgeR`, or `<save_dir>/z_score/<name>/` for `z_score` | The implementation requires `--save_dir` for all methods. This is more specific than the prose in the docs. |
| `analyse` | `delt-hit analyse enrichment` | `--method counts`, `--save_dir`, `--analysis_config`, `--name` | None beyond method selection | `<save_dir>/counts/<name>/data.csv`, `samples.csv`, `enrichment_counts.R` | The generated R script is written, but not executed by the CLI wrapper. |
| `analyse` | `delt-hit analyse enrichment` | `--method edgeR`, `--save_dir`, `--analysis_config`, `--name` | None beyond method selection | `<save_dir>/edgeR/<name>/data.csv`, `samples.csv`, `enrichment_edgeR.R` | Same pattern as `counts`: prepares input CSVs and an R script. |
| `analyse` | `delt-hit analyse enrichment` | `--method z_score`, `--save_dir`, `--config_path`, `--counts`, `--name` | None beyond method selection | `<save_dir>/z_score/<name>/enrichment_z_score.R` | The CLI validates inputs and generates the z-score R script only. |
| `dashboard` | `delt-hit dashboard` | `--config_path <config.yaml>`, `--counts_path <counts.txt>` | `--selection_name` | No documented stable file output; launches a Dash web app, default port `8050` | `selection_name` is optional because the code can infer it from the counts path layout. |

## Notes

- `analyse enrichment` is currently a script generator, not a full analysis runner. The generated `data.csv`, `samples.csv`, and `enrichment_*.R` artifacts are the direct outputs of the CLI.
- The `demultiplex run` command is intentionally excluded because it has been removed from the public CLI API.
- Helper-like public methods exposed incidentally by `jsonargparse`, such as `library compute_properties`, `library plot_property`, and `analyse run`, are intentionally excluded from this user-facing reference.
