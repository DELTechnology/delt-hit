# DELT-Hit — Project Context for Claude Code

## What This Is
DELT-Hit (DNA-Encoded Library Technology Hit Identification) is an open-source
Python CLI tool for analyzing DNA-encoded chemical library (DEL) screening data.
It converts raw FASTQ reads into ranked hit lists and ML-ready chemical data.
Developed at ETH Zurich, MIT License.

## Domain Context
- DEL = DNA-Encoded Library (millions of tagged small molecules screened against proteins)
- Naive library = unselected library, sequenced to assess synthesis quality
- PureDEL = self-purified library where only complete products are released from solid support
- Enrichment = statistical over-representation of a compound after selection (= binding signal)
- Synthon levels: monosynthon (1 BB), disynthon (2 BBs), trisynthon (full compound)
- Building blocks (BBs) are combined via reactions defined as SMIRKS

## Project Structure
```
src/delt_hit/
├── cli.py              # Click CLI entry point
├── init/               # Excel → YAML config
├── demultiplex/        # FASTQ → counts matrix (Cutadapt)
├── library/
│   ├── enumerate.py    # BB + SMIRKS → SMILES
│   ├── properties.py   # MW, logP, TPSA, QED
│   ├── represent.py    # Morgan FP, BERT embeddings
│   └── assess.py       # NEW: naive library synthesis QC
├── analyse/
│   ├── enrichment.py   # edgeR, z-score, Poisson ML methods
│   ├── aggregate.py    # NEW: multi-level synthon aggregation
│   ├── rank.py         # NEW: consensus scoring
│   └── qc.py           # QC metrics + HTML report
├── explore/            # NEW: chemical space analysis
│   ├── umap.py         # UMAP projections
│   ├── cluster.py      # HDBSCAN clustering
│   └── sar.py          # per-position BB activity analysis
├── ml/                 # NEW: ML integration
│   ├── prepare.py      # balanced dataset creation
│   ├── train.py        # RF, MLP, ChemProp
│   └── predict.py      # virtual screening
└── utils/
```

## Key Dependencies
Python 3.10+, RDKit, Cutadapt, Click, Polars, R + edgeR,
scikit-learn, PyTorch, UMAP-learn, HDBSCAN

## Coding Conventions
- Type hints on ALL function signatures
- Google-style docstrings
- pathlib.Path, never os.path
- logging module, never print()
- Polars over Pandas for new code
- snake_case column names in all dataframes
- Tests mirror src/ structure in tests/

## Architecture Rules
- CLI commands call module code (thin CLI layer)
- Config flows through YAML (never hardcode paths)
- R scripts are GENERATED by Python, not hand-edited
- All intermediate files use .parquet format
- QC produces data_quality.json consumed by analysis
- Naive library yields feed into enrichment normalization
- Multi-level synthon analysis runs at ALL 7 levels (3-cycle library)
