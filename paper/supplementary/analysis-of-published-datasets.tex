\subsection{Analysis of published datasets}

To assess the applicability of DELT-Hit to previously published DEL selections, we re-analysed two literature datasets distributed with the supporting material: the NF2 dataset reported by Favalli et al.\cite{ref37} and the Pure-DEL dataset reported in Science.\cite{ref38}

For the Favalli dataset, we focus on the \texttt{lane-1-fasta} re-analysis. The rerunnable workflow is provided in \path{supporting_material/experiments/favalli/run.sh}, and step-by-step instructions for analysing the original FASTA file with DELT-Hit are given in \path{supporting_material/README.md}. The corresponding comparison script, \path{supporting_material/experiments/favalli/compare_selections.py}, shifts the DELT-Hit \texttt{code\_0}/\texttt{code\_1} identifiers to the published 1-based numbering and then matches them to the \texttt{CodeA}/\texttt{CodeB} columns of the original evaluation table. In this way, the DELT-Hit re-analysis reproduces the published count table that was originally generated with the C++ evaluation workflow referenced in the study. An example selection excerpt is shown in Table~\ref{tab:favalli-example}.

The Pure-DEL library was analysed in the original study with a further-developed version of the same C++ analysis lineage. In our re-analysis, DELT-Hit was run from the original FASTQ files using \path{supporting_material/experiments/pure-del/run.sh}, and the resulting count tables were compared with the Zenodo-deposited selection tables using \path{supporting_material/experiments/pure-del/compare_selections.py}. This script shifts DELT-Hit \texttt{code\_0}/\texttt{code\_1}/\texttt{code\_2} identifiers to the deposited 1-based numbering and matches them to the \texttt{Code1}/\texttt{Code2}/\texttt{Code3} columns in the original tables. Across the two lane-specific reruns, the deposited selection count tables are recovered exactly for the corresponding deposited outputs, showing that the published Pure-DEL counts can be reproduced directly from the original sequencing data within the DELT-Hit workflow. An example selection excerpt is shown in Table~\ref{tab:puredel-example}.
