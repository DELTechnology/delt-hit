# Figure Guidelines

Reference:

- Google Drive link shared by the editor: [figure guidance](https://drive.google.com/file/d/10nwyH47XJvzmtGleKS2YopG-6hDw6jeB/view)
- Official Nature-branded journals artwork guide: [nprot-guide-to-preparing-final-artwork.pdf](https://www.nature.com/documents/nprot-guide-to-preparing-final-artwork.pdf)

## Nature Protocols sizes

For `Protocol`, `Protocol Extension`, and `Protocol Update` content:

- Single-column width: `135 mm`
- Full-page width: `180 mm`

Maximum figure heights depend on caption length:

- Caption `< 300 words`: about `199 mm` at `135 mm` width, about `205 mm` at `180 mm` width
- Caption `< 150 words`: about `210 mm` at `135 mm` width, about `214 mm` at `180 mm` width
- Caption `< 50 words`: about `222 mm` at `135 mm` width, about `222 mm` at `180 mm` width

## Text and fonts

- Use a sans-serif typeface, preferably `Helvetica` or `Arial`
- Maximum text size: `7 pt`
- Minimum text size: `5 pt`

## File types

- Save graphs, charts, schematics, and other line art as vector files: `AI`, `EPS`, or `PDF`
- Save photographs and complex rendered illustrations as bitmap files
- Bitmap images should be at least `300 dpi` at final use size
- Do not upsample low-resolution images artificially

## Mixed figures

- Build final composite figures in a vector-capable tool such as `Adobe Illustrator` or `Microsoft PowerPoint`
- Keep overlay elements editable as vectors: text, axes, arrows, boxes, lines, and scale bars
- Place bitmap panels at `300 dpi` or at their native resolution if lower
- Avoid flattening vector elements into raster output

## Software-specific notes

- `Word` is not recommended for figure assembly
- `Excel` figures should be converted to `PDF`
- `PowerPoint` is acceptable if the figure remains fully editable
- Avoid graphical effects such as drop shadows, bevels, and 3D rotation
- `Photoshop` is not recommended for figure creation; if used, text must remain editable and line art must remain vector-based

## Color and permissions

- Original research content should be supplied in `RGB`
- Clarify the source and permissions for any third-party image
- Avoid images from sources with unclear copyright status

## Practical checklist

- Prepare each figure close to final display size
- Make sure labels remain legible at final size
- Keep figure captions short when possible to preserve usable figure height
- Use vector export whenever the content is primarily line art
- Check that all panels in a multipart figure remain readable after reduction
- Aim to keep each final figure file under about `50 MB`
